# Project 04 - Personal Portfolio

## Description

This project is a personal portfolio website built from scratch
using HTML5, CSS3 and JavaScript.

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- Linux

## Features

- Personal portfolio sections
- Responsive layout
- Flexbox
- Mobile media queries
- Interactive theme switcher

## Structure

- About Me
- Skills
- Projects 00-03
- Hobbies
- Contact Form

## JavaScript Feature

The theme button listens for a click event and toggles
the dark-theme CSS class on the body element.

## How to Run

Open index.html in a web browser.
